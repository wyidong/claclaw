# 找视频发给用户

目标是快：一次搜索、挑一个、下载、发送，通常 30 秒内完成。不要先问用户细节，按下面的默认值直接做，发完再问要不要换。

## 命令

```sh
~/.claclaw/bin/claclaw-video search "关键词" [--n 8] [--max 600] [--site bili|yt|all]
~/.claclaw/bin/claclaw-video get <视频网址> [--clip 秒] [--max-mb 45] [--out 目录]
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claclaw-video.cmd`；没有这个命令时直接 `node <claclaw 仓库>/skills/claclaw-video/video.mjs`。）

- `search`：同时搜 B 站和 YouTube，每行 `序号 来源 时长 播放量 标题 网址`（制表符分隔），`--max` 只要多少秒以内（默认 600），时长 `?` 表示没取到。大约 10 秒。
- `get`：下载成 H.264 + AAC 的 mp4（手机都能放），最后一行 stdout 打印文件路径，stderr 打印大小。自动在 720p / 480p / 360p 里挑不超过 `--max-mb`（默认 45MB）的；还超就用 ffmpeg 压。`--clip 60` 只要开头 60 秒（只下这一段，快）。
- 第一次用会自动下载 yt-dlp 到 `~/.claclaw/tools/`。B 站要 ffmpeg 合并音视频。YouTube 需要能出墙：自动用环境变量里的代理或本机 7890 / 7897 端口，也可以 `--proxy http://…`。

## 流程

1. **想关键词**：用户说「讲西游故事的短视频」→ 搜 `西游记 故事`；要儿童向加「动画 / 儿童 / 绘本」，要片段加具体情节（「三打白骨精」）。中文内容 B 站结果通常更合适。
2. **search**，「短视频」默认 `--max 300`，没说长度用默认 600。
3. **挑一个**：标题最贴题的；同样贴题选播放量高的；避开明显是合集、全集、预告、纯音乐 MV、标题党。
4. **get** 下载。失败（「not available」、地区限制、要登录、会员专享）就换列表里下一个，不要在同一个上重试。
5. **发送**：Claude 会话用 `send_file` 工具发出文件，聊天里直接显示播放器。没有 send_file 的 Claw：在回复里用反引号写出文件路径，并告诉用户视频要在电脑上看（手机点路径放不了视频）。
6. 回复一两句：视频标题、时长、出处网址。

## 注意

- 只给用户个人观看。不要下载付费 / 会员内容，不要绕过登录或地区限制。
- 视频超过 50MB 发不出去：加 `--clip` 截一段，或调小 `--max-mb`。
- 用户给了具体链接（B 站、YouTube、抖音、微博等 yt-dlp 支持的站点）时，跳过搜索直接 `get`。
- 下载的文件在系统临时目录 `claclaw-video/` 下，发完不用留。
