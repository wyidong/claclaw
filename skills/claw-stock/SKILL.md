# 查 A 股行情

查沪深京的个股、指数、场内基金（ETF / LOF）：现价、涨跌、成交额、换手、市盈率、市值，和一段时间的走势。数据现查，来自腾讯证券、东方财富的公开行情。**股价、涨跌、市值这些数字只用这个命令的输出，不要凭记忆说，不要自己编。**

## 命令

```sh
~/.claclaw/bin/claw-stock "贵州茅台"              # 一只：现价、涨跌、成交、估值 + 近 60 个交易日走势。名字、简称、拼音首字母、6 位代码都行
~/.claclaw/bin/claw-stock k 比亚迪                # 一段时间的走势：区间涨跌、最高最低、均线、最近 5 天（默认 60 个交易日）
~/.claclaw/bin/claw-stock k 比亚迪 --days 120     # 换个时长：一个月 20、一个季度 60、半年 120、一年 240（最多 500）
~/.claclaw/bin/claw-stock cmp 茅台 五粮液 泸州老窖   # 几只放一起比（2～6 只）
~/.claclaw/bin/claw-stock find 平安               # 这个名字对得上哪几只（重名、不知道代码时）
~/.claclaw/bin/claw-stock flow                    # 行业板块的主力资金：当日净流入最多的 10 个、净流出最多的 5 个（31 个行业大类）
~/.claclaw/bin/claw-stock flow --days 5           # 近 5 日（也可以写 10：近 10 日。只有当日、5 日、10 日三档）
~/.claclaw/bin/claw-stock flow 细分               # 换成细分行业（一百多个，比如半导体、通信设备、电池），也可以加 --days
~/.claclaw/bin/claw-stock top                     # 涨幅榜：沪深主板、创业板 / 科创板、北交所各排前 6，写清各有几只涨停，带全市场涨跌家数
~/.claclaw/bin/claw-stock top 跌                  # 跌幅榜（同样按板块分）
~/.claclaw/bin/claw-stock top 成交额              # 成交额榜：全部 A 股前 15
~/.claclaw/bin/claw-stock top 换手                # 换手榜：换手率最高的，三个板块各排前 6
~/.claclaw/bin/claw-stock top 量比                # 量比榜（量能榜）：比前 5 天放量最多的
~/.claclaw/bin/claw-stock top 主力                # 主力净流入榜：个股的主力净流入最多的；净流出榜写 top 主力流出
~/.claclaw/bin/claw-stock top 北交所              # 只排一个板块，前 15：主板、双创（创业板和科创板）、北交所；也可以和 跌 / 成交额 / 换手 / 量比 / 主力 一起写
~/.claclaw/bin/claw-stock lhb                     # 龙虎榜：最近一个公布日上榜的股票，净买入最多的 10 只、净卖出最多的 5 只
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claw-stock.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-stock/stock.mjs`。）

## 怎么回复

- 命令输出一个 ```` ```stock ```` 代码块，**整块原样贴进回复**（包括开头的 ```` ```stock ```` 和结尾的 ```` ``` ````，每一行都要，那一长串逗号分开的数字是画折线用的，也不能删）。不要改写数字，不要改成表格或列表。claclaw 会把它画成行情卡片：涨是红、跌是绿，走势画成折线。
- 卡片前面只写一句话，比如「贵州茅台最新行情：」。**卡片里已经有的数字不要在卡片外面再写一遍。**
- `find` 输出的是普通表格，原样贴。
- **报价时间照输出里写的说**。输出写「收盘价，最近一个交易日」时，不要说成「今天」「现在」：周末、节假日、没开盘时拿到的是上一个交易日的收盘价。
- **只说数据，不给买卖建议**。用户问「能不能买」「会不会涨」「该不该卖」「目标价多少」：把行情贴出来，说明这里只提供数据，不做预测和推荐。不要说「建议买入 / 持有 / 卖出」「后市看涨 / 看跌」「支撑位 / 压力位」这类话。
- 可以照着输出说事实，比如「近 60 个交易日涨了 13%」「现价在 20 日均线上方」；不要从这些事实推出该怎么操作。
- 卡片最后有「名字相近的还有…」：说明这个名字不止一只，贴出来的是最像的那只。原样留着，让用户自己确认。
- **颜色是红涨绿跌**（A 股的习惯，和美股相反）。说到颜色时照这个说，不要说「绿了是涨」。
- 用户一次问几只：用 `cmp`，不要一只一只跑。
- 用户问「最近走势」「近半年」「这一年」：用 `k`，按时长写 `--days`。
- 用户问「哪个板块最热 / 资金流入最多 / 资金在买什么」：用 `flow`。问「近期」「最近」「这几天」用 `--days 5`；问「今天」不加；问得细（「半导体还是通信设备」）用 `flow 细分`。
- 说板块资金时**叫它「主力净流入」，并说明这是按大单成交估算的**。不要说成「机构在买」「聪明钱进场」「资金抄底」，也不要因为流入多就说这个板块会涨。
- 用户问「涨幅榜 / 谁涨得最多 / 涨停多少只」用 `top`，「跌幅榜 / 谁跌得最多」用 `top 跌`，「成交最大 / 最活跃」用 `top 成交额`。只问某个板块（「创业板涨幅榜」）就带上板块名。
- **涨跌幅榜是按板块分开排的**，因为上限不一样（主板 10%、创业板和科创板 20%、北交所 30%）。不要把三个板块混在一起说「全市场第一名」；涨停的那几只是并列的（榜里按成交额排），不要说成谁比谁涨得多。
- 用户问「换手榜 / 换手率最高」用 `top 换手`，「量比榜 / 量能榜 / 谁放量了」用 `top 量比`，「主力榜 / 哪些股票主力流入最多」用 `top 主力`（问流出用 `top 主力流出`），「龙虎榜」用 `lhb`。
- 个股的主力净流入和板块的一样，**是按大单成交估算的**，照这个说。
- **龙虎榜照卡片上的日期说**：交易所收盘后才公布，傍晚以前查到的是上一个交易日的，不要说成「今天的龙虎榜」。「净买额」只是上榜席位的买入减卖出，不要说成这只股票全天的资金流向，也不要说「机构在买」「游资进场」。
- 说榜上的股票时只说数据。不要叫「龙头」「妖股」「牛股」，不要说「值得关注」「可以打板」，不要因为上了榜就说它还会涨。
- 命令说没找到：照实告诉用户，可以用 `find` 试试别的写法；不要换一只相近的顶上，也不要去网上找数字。
- 命令说行情接口没通：照实说过一会儿再试，**不要用记忆里的旧价格顶上**。

## 说明

- 只有沪深京的个股、指数和场内基金。港股、美股、场外基金、期货、债券查不了，直接告诉用户。
- 走势用的是**前复权**价格（分红、送股后把以前的价格往下调过），所以以前的价格和当时看到的不一样，这是正常的。指数不复权。
- 成交量的单位是手（1 手 = 100 股），成交额、市值的单位是元。
- 写 6 位代码时按个股查：`000001` 是平安银行。要查上证指数写名字「上证指数」。
- 行情可能有延迟，不是逐笔实时的；不能用来盯盘、下单。
- 板块资金只有行业板块（大类、细分）的主力净流入。个股的资金只有当天的主力净流入榜 / 净流出榜，查不了指定某一只的资金流。没有概念板块（人工智能、机器人这类题材）、北向资金、融资融券，直接告诉用户。
- 龙虎榜只有最近一个公布日的榜单：上榜原因、净买额。没有买卖席位明细（哪个营业部、哪家机构买了多少），也查不了以前某一天的。同一只因为几个原因上榜的合成一条；标「3 日」的是连续三个交易日累计偏离上榜的，净买额是三天合计的。可转债、B 股不在里面。
- 量比在刚开盘时偏高，新股的量比不准（没有可比的 5 日均量），卡片里标了「新股」。
- 行业大类之间不重叠，所以有「合计」；细分行业的卡片不写合计。当日的卡片有「领流入」（这个板块里净流入最多的那只），近 5 日、10 日的没有。
- 排行榜只有当天（最近一个交易日）的，没有「近一周 / 近一月涨幅榜」，也不能按行业、市值筛。榜里标「新股」「不限幅」的是上市头几天或恢复上市、当天不设涨跌幅上限的，所以涨幅能超过上限。ST 股票和别的股票排在同一个榜里。
- 「全市场上涨 / 下跌多少只」是沪、深、北三个市场加起来的。
- 没有财务报表、公告、研报、选股和回测，这些命令给不了，不要硬编。
- 来源是行情网站页面自己用的公开接口，不用登录、没有签名，但也不是有授权的正式接口：对方改了就可能查不到，这时命令会说没通。
