# 换皮肤

只在现有主题库里选（下面的表），**不要自己编颜色、不要改 CSS**。你的活是听懂用户想要什么感觉，挑出最合适的一个直接换上，再挑 2～3 个相近的当备选。**只用这个命令换，不要叫用户去设置里手动改。**

## 命令

```sh
~/.claclaw/bin/claw-theme set 九紫离火 --alt 未,申,子午流注   # 换上第一个，并给出备选卡片（主题可写 id、名字或别名）
~/.claclaw/bin/claw-theme show 深色,酉,丑                    # 只给卡片让用户挑，不换
~/.claclaw/bin/claw-theme                                    # 主题库 + 现在用的哪个（* 标出）
~/.claclaw/bin/claw-theme now                                # 现在用的哪个、背景图开没开
~/.claclaw/bin/claw-theme img off                            # 关掉时辰背景图，改纯色（img on 打开）
~/.claclaw/bin/claw-theme bg --on 辰 --alt 卯,子              # 用户在聊天里刚发的图当背景（--on 配色用哪个时辰，--fit center 不拉伸居中）
~/.claclaw/bin/claw-theme bg /路径/图.jpg --on 辰              # 用电脑上的图片文件当背景
~/.claclaw/bin/claw-theme bg reset                           # 不用自己的图，回到时辰自带的图
~/.claclaw/bin/claw-theme fit center                         # 背景图改成原尺寸居中（fit cover 改回按比例拉伸铺满）
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claw-theme.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-theme/theme.mjs`。）

## 怎么挑

- **先换，再给备选**：用户说了想要的感觉，就直接 `set` 最合适的那个，`--alt` 带 2～3 个备选。不要先问「你想要哪种」。
- **备选要有区别**：一个同色系的深 / 浅版本（粉 → 未；红 → 午），一个气质接近的别的颜色，必要时一个「跟随系统」兜底。备选里不要放刚换上的那个。
- **说法对照**：
  - 「暗一点 / 太亮了 / 晚上用」：在深色里挑（dark、酉、丑、寅……）；「太暗了 / 亮一点」：在浅色里挑。
  - 「护眼」：浅的选子（薄荷绿）或辰（米黄），深的选丑（墨绿）。
  - 「喜庆 / 过年 / 中国风」：午（深红）、未（浅粉红）、辰（米黄暖金）。
  - 「简洁 / 高级 / 低调」：light、寅（石墨灰）、卯（雾蓝灰）。
  - 「随便换一个 / 给我惊喜」：挑一个和现在明暗相反、颜色不同的（先跑 `now` 看现在用的）。
  - 「有哪些主题」：`show` 挑 3 个风格差得最远的，或者用户问全部时把上面的表简要说一下再 `show` 几个。
  - 「换回去 / 恢复默认」：`set auto`。
- 用户直接点名（「换成九紫离火」「午时那个」）：就换那个，备选给 2 个相近的。
- **用户发图要当背景**（「用这张当背景 / 设成壁纸」）：先看图，再 `bg`（不写路径就是用户在聊天里最近发的那张）。用户说的是电脑上的某个图片文件就写路径。
  - `--on` 挑配色：图偏亮选浅色时辰（子 薄荷绿、卯 雾蓝灰、辰 米黄、未 浅粉、申 天蓝、亥 蜜桃橙），图偏暗选深色时辰（丑 墨绿、寅 石墨灰、巳 暗金、午 深红、酉 深蓝、戌 焦糖），颜色和图的主色接近的优先；`--alt` 再给 2 个也合适的。
  - 默认按比例拉伸铺满；用户说「不要拉伸 / 原图大小 / 居中」加 `--fit center`，已经设好的用 `fit center` 改。
  - 背景图只在时辰主题下显示（换上去时主题会自动变成时辰），所以 `--on` 和 `--alt` 只能写时辰主题（子午流注或某个时辰）。
  - 命令说「没找到用户发来的图」：请用户再发一次图。
- 「不要背景图 / 背景太花 / 纯色背景」：`img off`；「要背景图 / 换成图片背景」：`img on`。只有子、卯、辰、未、申、亥 6 个浅色时辰（含子午流注轮到它们时）有背景图，别的主题本来就是纯色。只关图不用给卡片。

## 怎么回复

- 命令输出的第一行（「已换成「…」」）和下面的 ```` ```theme ```` 代码块**原样贴进回复**（包括开头的 ```` ```theme ```` 和结尾的 ```` ``` ````）。claclaw 会画成主题卡片：上面一小块那个主题的样子，点哪张换哪个，正在用的打勾。
- 卡片前用一句话说为什么选这个（比如「晚上看，换成深蓝的酉时，不刺眼：」），不要长篇介绍每个主题。
- 不要把卡片改成表格或列表。

## 说明

- 换主题对这台电脑上 claclaw 的所有网页（手机、电脑）都生效，打开着的马上变，没打开的下次打开时变。
- 命令报「claclaw 没认这个命令」：claclaw 还是旧版本，要重启 claclaw 才能用；告诉用户，不要去改文件。
- 背景图在会话列表和聊天页底下，和时辰自带的图铺法一样；手机拍的大图、HEIC 都行，电脑会压成合适的大小。
- 主题库是固定的，用户要的颜色库里没有（比如「绿色加金色」）：选最接近的，并直说没有完全一样的。
