# 找电影

从 YouTube 上版权方的官方频道（爱奇艺、优酷、腾讯、芒果、华策、TVB、美亞、天映…）、小而专的官方片库频道（Mosfilm、高尔基电影制片厂、韩国电影资料馆「韩国古典电影」、Grjngo 西部片，关键词说到苏联 / 俄罗斯、韩国、西部片时整个翻）、Dailymotion 官方账号、NFB 加拿大国家电影局（公益片库：纪录片、动画、剧情片，英文关键词或「纪录片」「加拿大」）、Internet Archive 的公版老片里找**免费公开的完整版**，带豆瓣 / IMDb 评分、年份、类型。**只用这个命令，不要自己编片名和链接。** 不先问用户细节，直接出片单。

## 命令

```sh
~/.claclaw/bin/claw-movie "类型 / 片名 / 演员" [--n 10]   # 片单
~/.claclaw/bin/claw-movie --latest [--n 50]                # 最新上映的华语电影（大陆 / 香港 / 台湾）
~/.claclaw/bin/claw-movie --pick 3                         # 用户挑了第 3 部：出播放链接
```

Windows 用 `%USERPROFILE%\.claclaw\bin\claw-movie.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-movie/movie.mjs`。

| 用户说 | 加的参数 |
| --- | --- |
| 好评 / 高分 | `--min 7`（中文片豆瓣分，外文片 IMDb 分） |
| 今年的 / 2026 年的 | `--year 2026`（约 20～30 秒） |
| 近几年 | `--since 2020` |
| 新上传的（不限年份） | `--new` |
| 最新上映 / 新片列表 / 前 N 部 | `--latest --n N`（第一次约 30 秒，之后 5～10 秒） |

## 怎么回复

- **片单就是播放列表**：输出里片名已经是 `[片名](网址)`，原样写成编号列表：`1. [片名](网址) · 2026-11-03 · 剧情/爱情 · 1:30 · 爱奇艺`（有评分就加上）。不用宽表格，手机上不好看。
- claclaw 里点片名就在聊天顶上的播放器播，列表留在下面，可以换片、上一部 / 下一部。**不要自动开播**，让用户自己点。
- 「播第 3 部」：`--pick 3`，把 `[片名](网址)` 单独写一行。片单记在上一次的结果里，不用再写关键词；用户换了要求就重新搜。
- 不分国籍时多换几种关键词各搜一次（「爱情」「romance」「Korean romance」…），合并后再给片单。
- 没有用户要的那部：如实说官方没免费放，**不去找盗版**。

## 投屏到电视

用户说「投到电视上」「在电视 / 投影上放第 2 部」：

```sh
claw-movie --tv                        # 局域网里能投的电视（和装 claclaw 的电脑连同一个路由器）
claw-movie --cast 2 [--to 电视名]      # 把上次片单里的第 2 部投过去（也可以 --cast 网址；--at 秒 从中间开始）
claw-movie --cast-status / --cast-pause / --cast-resume / --cast-stop
```

- 不加 `--to`：只有一台电视就投它，否则投上次投过的那台；都不是就会列出电视名，问用户投哪台，再用 `--to`。
- 一台电视盒子上常常有好几个接收端（系统自带的、腾讯视频、芒果 TV…），名字不同，都能投。
- 能投 YouTube、Dailymotion、Internet Archive 的片子；NFB 的暂时投不了。约 10～20 秒电视开始播。
- 也可以告诉用户：网页上播放器的标题条有个电视图标，点它选电视，手机就成了遥控器（暂停、拖进度、停止投屏）。
- 投出来没声音：多半是电视那边的音量 / 声音输出（比如设成了耳机），让用户用遥控器调。

## 说明

- 官方频道免费放的多是网络电影；院线好评新片一般只在付费平台，找不到就如实说。
- 只收 1～4 小时的完整版，预告、解说、剪辑、合集、晚会小品都排除；同一部片在几个频道只留一个。盗传的「XX 影院」频道不收。
- 不收 B 站（长片都是搬运，官方片要登录）、央视频 / 西瓜 / 1905（不让嵌入）、Tubi / Pluto（限地区）。
- 要能上 YouTube（自动用环境变量里的代理或本机 7890 / 7897 端口）。评分来自豆瓣、IMDb、猫眼，豆瓣限流时显示「暂无」，不代表片子差。
