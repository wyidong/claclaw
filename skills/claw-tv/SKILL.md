# 电视频道直播

和电影技能一样**先平台、再频道**：`platforms.json` 是事先核对过的官方平台（央视网、央视频、各台的官方平台、官方 YouTube 频道……），每个平台下面挂它能看的台。同一个台可能在几个平台都能看（CCTV 在央视网、央视频……），找台时每个平台一张卡。YouTube 上正在播哪几场是现查的。**只用这个命令给地址，不要自己编网址、不要用别的网站。**

## 命令

```sh
~/.claclaw/bin/claw-tv "四川卫视"      # 找一个台：台名、简称都行（湖南台、芒果台、CCTV5、央视五套、凤凰、TVBS……）
~/.claclaw/bin/claw-tv platforms       # 有哪些平台、各有几个台（平台卡片）
~/.claclaw/bin/claw-tv list            # 全部，按平台分组（央视网、YouTube、各台官网……）
~/.claclaw/bin/claw-tv list 卫视       # 只列某一类台（仍按平台分组），也可以写平台名（list 央视网）：央视 卫视 少儿 地方 香港 澳门 台湾 海外（华人台） 国际（外语台）
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claw-tv.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-tv/tv.mjs`。）

## 怎么回复

- 命令输出一个 ```` ```tv ```` 代码块，**整块原样贴进回复**（包括开头的 ```` ```tv ```` 和结尾的 ```` ``` ````），不要改成表格或链接列表。claclaw 会把它画成频道卡片：点卡片新开页面去官网看；带 ▶ 的（YouTube 官方直播、CGTN）点了在聊天里直接播。
- 卡片前面只写一句话，比如「四川卫视官方直播，点卡片去看：」。不要再把网址另写一遍。
- 卡片的说明里写了「要登录」「只在香港能看」「进去后点某个频道」等，回复里不用重复，除非用户问。
- 找一个台出了几张卡：是同一个台在不同平台（或 YouTube 上同时播着的几场），都给，用户自己挑。
- 用户问「有哪些平台 / 在哪能看电视」时用 `platforms`。
- 用户一次要几个台：合在一个 ```` ```tv ```` 块里（多次运行命令，把每次输出的行合并成一个块）。
- 用户问「有哪些台 / 都发我」时用 `list`：输出已经**按平台分好组**（央视网、YouTube、各台官网……，同一个网站上的台放一起），小标题和代码块整段原样贴。claclaw 的用户以华人为主：推荐、举例时先给中文台，外语台放后面。
- 命令说没有这个台：直接告诉用户频道表里没有，给 `list` 里相近的；不要去网上找来路不明的直播源。

## 说明

- 电视台官网的直播流大多带签名、版权保护，或者不让别的网站嵌入，所以只能点过去在官网看，claclaw 里放不了。这是各台的限制，不要尝试抓流、破解。
- YouTube 的卡片在中国大陆要翻墙才能看。
