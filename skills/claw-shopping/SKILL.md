# 购物：搜商品

在拼多多（多多进宝官方接口）按关键词搜商品，命令输出商品卡片，用户点卡片跳到拼多多下单。**只用这个命令给商品和链接，不要自己编商品、价格或网址，也不要去别的网站找。** 现在只接了拼多多；淘宝、京东还没有，用户问到就照实说。

## 命令

```sh
~/.claclaw/bin/claw-shopping "保温杯"                  # 综合排序，6 个
~/.claclaw/bin/claw-shopping "保温杯 316 不锈钢" --max 50   # 券后价 50 元以内（--min 20 设下限）
~/.claclaw/bin/claw-shopping "蓝牙耳机" --sort 销量        # 排序：综合（默认）、价格（低到高）、价格高、销量
~/.claclaw/bin/claw-shopping "保温杯" --n 10              # 要几个，最多 10
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claw-shopping.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-shopping/shopping.mjs`。）

## 怎么回复

- **把用户的需求翻成关键词**：品类 + 关键属性（材质、容量、适用人群），别写成一句话；预算写进 `--max` / `--min`，「便宜的」用 `--sort 价格`，「卖得好的」用 `--sort 销量`。
- 命令输出一个 ```` ```shop ```` 代码块，**整块原样贴进回复**（包括开头的 ```` ```shop ```` 和结尾的 ```` ``` ````），不要改成表格或链接列表。claclaw 会把它画成商品卡片：点卡片跳拼多多。
- 卡片前面写一两句话：这次按什么搜的、挑选建议（比如「第 2 个最便宜、第 3 个销量最高」，只根据卡片上的标题、价格、销量说，不编参数和评价）。不要把网址再写一遍。
- 用户想多比较：换关键词或排序再搜一次，几次的结果分开贴（每次一个块）。
- 命令说没搜到：换个更通用的说法再搜一次；还没有就照实告诉用户。
- 命令说「暂时限制了查询」：告诉用户过一会儿再试，不要反复重试。

## 说明

- 价格是券后价（拼团价减去优惠券），以拼多多页面为准；卡片上的价格、销量是搜索那一刻的。
- 链接是多多进宝的推广链接：用户下单价格不变，平台给开发者一点佣金。用户问到就照实说。
- 一个词 15 分钟内重复搜给的是同一批结果；拼多多对只查不买的账号会限制查询，不要连着搜很多次。
