# 购物：搜商品

在拼多多（多多进宝官方接口）按关键词搜新品；加 `--platform 转转` 在转转（转转开放平台官方接口）搜二手在售商品。命令输出商品卡片，用户点卡片去平台下单。**只用这个命令给商品和链接，不要自己编商品、价格或网址，也不要去别的网站找。** 现在接了拼多多、转转；淘宝、京东还没有，用户问到就照实说。

## 命令

```sh
~/.claclaw/bin/claw-shopping "保温杯"                  # 综合排序，6 个
~/.claclaw/bin/claw-shopping "保温杯 316 不锈钢" --max 50   # 券后价 50 元以内（--min 20 设下限）
~/.claclaw/bin/claw-shopping "蓝牙耳机" --sort 销量        # 排序：综合（默认）、价格（低到高）、价格高、销量
~/.claclaw/bin/claw-shopping "保温杯" --n 10              # 要几个，最多 10
~/.claclaw/bin/claw-shopping "iPhone 15 Pro 256G" --platform 转转 --max 5000   # 转转二手；排序：综合、最新、价格、价格高（没有销量）
~/.claclaw/bin/claw-shopping 详情 https://zz3.cn/xxxx      # 转转商品详情、质检（链接来自转转卡片）
~/.claclaw/bin/claw-shopping 行情 "iPhone 15 Pro 256G"     # 二手成交价区间
~/.claclaw/bin/claw-shopping 估价 "iPhone 13 128G 国行 电池85% 无维修" [--img 照片路径]   # 回收估价
~/.claclaw/bin/claw-shopping 问 "七天无理由退货怎么申请"     # 转转售后、规则
```

（Windows 是 `%USERPROFILE%\.claclaw\bin\claw-shopping.cmd`；没有这个命令时用 `node <claclaw 仓库>/skills/claw-shopping/shopping.mjs`。）

## 怎么回复

- **把用户的需求翻成关键词**：品类 + 关键属性（材质、容量、适用人群），别写成一句话；预算写进 `--max` / `--min`，「便宜的」用 `--sort 价格`，「卖得好的」用 `--sort 销量`。
- 命令输出一个 ```` ```shop ```` 代码块，**整块原样贴进回复**（包括开头的 ```` ```shop ```` 和结尾的 ```` ``` ````），不要改成表格或链接列表。claclaw 会把它画成商品卡片：点卡片跳拼多多。
- 卡片前面写一两句话：这次按什么搜的、挑选建议（比如「第 2 个最便宜、第 3 个销量最高」，只根据卡片上的标题、价格、销量说，不编参数和评价）。不要把网址再写一遍。
- 用户想多比较：换关键词或排序再搜一次，几次的结果分开贴（每次一个块）。
- **先看下面「能搜到哪些品类」**：表里「基本搜不到」的品类也照常搜一次（平台随时可能放开）；0 个或只有杂牌山寨机，就告诉用户「这类商品能不能搜到取决于拼多多平台，目前推广库里还没有」，请他在拼多多 App 的「百亿补贴」或品牌官方店买；可以帮他按预算和用途挑型号，但不编价格和链接。
- 命令说没搜到：换个更通用的说法再搜**一次**；还没有就照实告诉用户，不要接着换词。
- 平台给什么就列什么，不自己挑掉、不拦关键词。结果里有没品牌、销量只有个位数到几十、参数夸张（「16 全网通」「256G」只卖几百元）的：照常列出，只提醒用户留意。
- 命令说「暂时限制了查询」：告诉用户过一会儿再试，不要反复重试。

## 转转（二手）：搜、详情、行情、估价、问答

转转是二手平台，主要是手机、电脑、平板、相机、游戏机等数码，还有奢侈品（包、表、大牌羽绒服）、潮玩、二手车；普通衣服、日用品、食品没有。

- 用户说「二手」「转转」：只搜转转。
- 品牌数码（上面表里拼多多「基本搜不到」的手机、电脑、平板、相机等）：先搜拼多多一次，同时搜转转，两个块分开贴，告诉用户转转的是二手、成色看标题开头（如「95A」「9B」：数字越大外观越新，字母 A 比 B 功能更好）。
- 其他新品需求不用搜转转。
- 用户想看某件转转商品的细节（质检、电池、保修、瑕疵）：`claw-shopping 详情 <那张卡片的链接>`（链接必须来自这次会话里转转卡片；命令说找不到就先重新搜一次）。输出开头是一张商品卡片（原样贴），后面是规格、权益、质检明细，挑用户关心的讲，瑕疵如实说。
- 用户问「XX 二手什么价 / 现在值多少」（想买、了解行情）：`claw-shopping 行情 "iPhone 15 Pro 256G"`，给的是最近一期成交最低价、最高价，说清楚这是成交行情，不是在售价，也不是他那台能卖的价。
- 用户想卖、问「我这台能卖多少 / 回收」：`claw-shopping 估价 "型号 + 容量 + 成色 + 电池 + 有无维修"`；用户发了照片就加 `--img 图片路径`（可多张；网址也行）。按输出讲：
  - 有分档就按档说（「成色最好约 X～Y 元」……），说明以上门质检为准，最后给回收入口链接；
  - 「还要用户确认这些条件」：把条件和选项用大白话问用户（最多问 1～3 个关键的），**不要替他选**；他选好后用 `--params '{"参数ID":选项ID}'` 再估一次（ID 用输出里括号和等号后面的）；
  - 「没认出型号 / 只认出品牌」：请用户说准型号（带容量）或发照片，再估一次；也可以把回收入口给他自己选。
  - 「描述里没用上的」：提醒用户补充对应情况会估得更准。
- 用户问转转的售后、规则（七天无理由、验机、退款多久到账、质保）：`claw-shopping 问 "七天无理由退货怎么申请"`，按返回内容回答，可附返回里的说明页链接。
- 不提工具名、参数这些内部细节；转转没有给我们佣金，不用替它推销。
- 命令说「这台电脑没有接转转」：说明这台电脑还没接转转，只用拼多多；说「转转凭证失效或过期」：告诉用户需要到 open.zhuanzhuan.com 重新登录拿凭证，别反复重试。

## 能搜到哪些品类

能被搜到的前提是商家给商品开了多多进宝推广（设了佣金）；拼多多没有「品牌手机不能推广」这类明文规则，品牌商家多半没开。下表是 2026-11 实测（每个词搜 10 个）：

| 情况 | 品类（实测关键词） |
|---|---|
| 基本搜不到（0 个） | 品牌手机（华为、iPhone、小米、荣耀、OPPO、vivo）、笔记本电脑、平板、手表手环、品牌耳机、电视、空调、冰箱、洗衣机、白酒（茅台、五粮液）、相机、显卡、机械键盘 |
| 只有杂牌或很少 | 泛称「手机」「智能手机」（杂牌机、老人机）、Switch（只有配件）、戴森（1 个） |
| 能搜到品牌货 | 小家电和厨具（美的电饭煲、九阳、苏泊尔）、服装鞋（耐克、安踏、李宁）、美妆（兰蔻、欧莱雅、完美日记）、母婴（飞鹤、帮宝适）、食品零食生鲜（三只松鼠、良品铺子、车厘子）、黄金首饰、充电宝、移动硬盘、手机壳等配件、日用百货 |

## 说明

- 拼多多的价格是券后价（拼团价减去优惠券），以拼多多页面为准；卡片上的价格、销量是搜索那一刻的。
- 转转的价格是卖家标价，二手商品一件一个，可能很快卖掉；点卡片打开转转网页详情（里面能看质检报告，也能跳转转 App）。转转链接不是推广链接。
- 拼多多链接是多多进宝的推广链接：用户下单价格不变，平台给开发者一点佣金。用户问到就照实说。
- 一个词 15 分钟内重复搜给的是同一批结果；每台电脑每分钟最多查 10 次（服务器防刷），命令说「请求太频繁」就等一分钟，不要连着搜很多次。
- 品牌数码、大家电搜不到不是关键词的问题，是这些商品没进推广库；哪天商家开了推广就能搜到，不用改命令。
